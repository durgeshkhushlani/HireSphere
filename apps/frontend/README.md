# HireSphere frontend

Next.js (App Router) + TypeScript + Tailwind CSS. Talks to the `apps/backend` Express API over `fetch` — see `NEXT_PUBLIC_API_URL` in `.env.local`.

```bash
npm run dev     # from apps/frontend, or from the repo root via workspaces
```

Full architecture/schema context lives in `hiresphere-implementation-plan.md` at the repo root.
